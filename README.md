

🛠️ Key Technical Features

Data Modeling: Established relational connections between order headers, line-item details, and performance target tables.

DAX Measures & Calculated Columns:

Combined field creation for hierarchy building (Category Type).

Financial computations (Revenue per Order, YTD Sales).

Categorical conditionally calculated dimensions (Sales Category).

Contextual filtering (Average Profit in Delhi).

Interactive Reporting: Multi-page dashboard layouts using interactive filters, tooltips, dynamic cards, and matrix summaries.

📊 Key Dashboard Insights

Target vs. Actuals: Comparative column chart and dynamic matrix displaying performance gaps across categories month-over-month.

Geographic Distribution: State-level funnel visuals and city-level geo-maps identifying high-performing regions.

Profitability & Volume Analysis: Scatter and Donut charts detailing sub-category profitability against sales quantities.
